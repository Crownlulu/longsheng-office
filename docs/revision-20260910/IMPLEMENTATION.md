1. 首页最终视觉采用已有蓝色品牌、卡片、表格和状态标签；不等待视觉稿。
2. 仅有一条现成业务事项，不能伪造两条新业务填满首页。用真实订单影响、岗位任务和处理记录增加信息密度；新场景仍等待产品定义。
3. 质量操作统一为“方案质量核验”，当前判定继续沿用既有 B 路径人工核验及凭据守卫；不新增评分或自动通过规则，不改写历史会议原文。
4. 重新生成复用当前部署选择的真实模型/规则通道。规则演示只据现有 A/B 事实回应反馈，明确不能生成未经证实的第三供应方案；原选择不因查询改变。
5. 内部配置保留已有后端 API 与部署环境变量，移除客户设置页面；不在前端存放密钥。
6. 任务投递仍为演示收件箱；办公办结不代表实物到货或订单交付。
